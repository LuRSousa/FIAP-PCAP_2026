# FIAP-PCAP_2026

Repositório acadêmico da disciplina **Pensamento Computacional e Automação com Python**, do curso de **Ciência da Computação da FIAP**.

O repositório tem como finalidade documentar o conteúdo desenvolvido ao longo da disciplina, reunindo exemplos de código, exercícios e atividades práticas realizadas durante as aulas.

## Sobre a disciplina

A disciplina apresenta os fundamentos do pensamento computacional e da lógica de programação utilizando **Python** como linguagem principal.

Ao longo do ano, são abordados conceitos fundamentais de programação, estruturas de controle, manipulação de dados e outros recursos necessários para o desenvolvimento de soluções computacionais.

Por se tratar de uma disciplina anual, o conteúdo é desenvolvido ao longo do **1º e 2º semestres de 2026**.

## Organização

O repositório está organizado em uma pasta para cada aula. Cada diretório contém os arquivos relacionados ao conteúdo e às atividades desenvolvidas naquele encontro.

> A estrutura será atualizada conforme novos conteúdos forem apresentados.

## Conteúdos

Até o momento, os seguintes conteúdos foram abordados:

| Conteúdo | Descrição |
|---|---|
| Variáveis e operadores | Declaração e utilização de variáveis, tipos de dados e operadores |
| Estruturas condicionais | Tomada de decisões utilizando estruturas como `if`, `elif` e `else` |
| Estruturas de repetição | Execução repetitiva de blocos de código utilizando estruturas como `for` e `while` |
| Vetores | Armazenamento e manipulação de conjuntos de dados |
| Dicionários e tuplas | Estruturas de dados e suas principais formas de utilização |

> Novos conteúdos serão adicionados ao longo do desenvolvimento da disciplina.
